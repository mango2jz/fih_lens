# Official evidence — combined translator (.NET/Toolkit)

Native researcher: /root/combined_docs. Retrieved 2026-10-06. Planning input; no dependency installation or execution authority.

- [CommunityToolkit.Mvvm 8.4.2](https://www.nuget.org/packages/CommunityToolkit.Mvvm/8.4.2): available, compatible with net10.0. Add only this planned package to WinUI and its linked-source test project, same pinned version.
- [MVVMTK0045](https://learn.microsoft.com/en-us/dotnet/communitytoolkit/mvvm/generators/errors/mvvmtk0045), [C# 13 partial properties](https://learn.microsoft.com/en-us/dotnet/csharp/whats-new/csharp-13), [language version](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/configure-language-version): annotated public partial properties avoid field-generator WinRT/AOT marshalling issues. .NET10/C#14 requires no preview setting.
- [RelayCommand generator](https://learn.microsoft.com/en-us/dotnet/communitytoolkit/mvvm/generators/relaycommand), [AsyncRelayCommand](https://learn.microsoft.com/en-us/dotnet/communitytoolkit/mvvm/asyncrelaycommand), [ObservableProperty](https://learn.microsoft.com/en-us/dotnet/communitytoolkit/mvvm/generators/observableproperty): async concurrency is disabled by default; token-aware methods support cooperative Cancel; property-dependent CanExecute requires explicit notification. Command execution/completion notifications are distinct from ViewModel-owned display-state writes.
- [HttpCompletionOption](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httpcompletionoption?view=net-10.0), [SendAsync](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httpclient.sendasync?view=net-10.0), [buffer cap](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httpclient.maxresponsecontentbuffersize?view=net-10.0), [ReadAsStringAsync](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httpcontent.readasstringasync?view=net-10.0): ResponseContentRead includes body buffering in completion, covering it with timeout and a 1_048_576-byte cap. ResponseHeadersRead would not provide the same guarantees. Pass caller token to send/read. .NET5+ timeout can be OperationCanceledException nesting TimeoutException; classify caller cancellation first.
- [HttpClient lifetime](https://learn.microsoft.com/en-us/dotnet/fundamentals/networking/http/httpclient-guidelines): reuse startup-owned HttpClient; choose/document PooledConnectionLifetime for endpoint/DNS. Dispose per-operation request/response, not injected client.
- [Required JSON properties](https://learn.microsoft.com/en-us/dotnet/standard/serialization/system-text-json/required-properties), [nullable JSON annotations](https://learn.microsoft.com/en-us/dotnet/standard/serialization/system-text-json/nullable-annotations): required ensures presence, not semantic validity. Nullable enforcement is opt-in and incomplete for root/generic/collection elements. Explicitly validate arrays, null elements, field types and nonblank required values before Core mapping.

Older Toolkit text describing partial properties as preview is publication-era guidance; current C# docs establish released language support. No SDK or general HTTP/JSON package is needed. Gemini/DeepSeek contracts are separate evidence.

Configured-limit classification: .NET10 `HttpRequestException.HttpRequestError == HttpRequestError.ConfigurationLimitExceeded` identifies configured response-limit failure, including MaxResponseContentBufferSize (also header limits). Map to InvalidResponse without exception-message matching; other transport failures remain Unavailable. [HttpRequestError](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httprequesterror?view=net-10.0), [.NET10 HttpContent source](https://github.com/dotnet/runtime/blob/v10.0.0/src/libraries/System.Net.Http/src/System/Net/Http/HttpContent.cs). Offline tests can exercise both declared Content-Length oversize and content that exceeds the cap without a known length using a handler-returned custom HttpContent.
